# [ADR-001] 什麼是好的專題提案？
Status: Accepted | Date: 2026.09.30 (Wed)

## Context

為了更好的做專題提案，我認為需要定義好「什麼是好的專題題目」。

## Decision

助教能接受的專題題目需要符合以下標準：

1. 用論文解釋問題

從助教的視角來看，他們並不認為我們能自己解決問題；因此他們會希望遇到比較困難的問題時
可以有相對應的論文作為參考。

2. 需要有現成的代碼

論文需要提供相對應的代碼，一方面降低專題實做難度，另一方面代碼可以避免論文上的歧異。

3. 評估訓練成本

ai 所需的訓練資源不可以高於 5090 的負擔範圍，否則模型訓練不起來。

4. 一定程度上的技術貢獻

對該應用提出更好的解決辦法。

補充：不需要很大的技術貢獻，對於專題生而言替換更好的模型頭也算是一種貢獻。

5. 創意上的貢獻

對該應用提出更好的創意貢獻。

補充：例如漫畫閱讀器可以透過檢測眼睛來達到翻頁的效果。

6. 和其他人做的東西要有所不同

舉人臉辨識為例子，或許在現實生活中這是一個被研究透的問題。

除非：
- 你解決了某個架構的漏洞、問題 -> 技術上的貢獻
- 你提出了人臉辨識相關的應用 -> 創意上的貢獻

因此，在確定一個專題題目之後，務必要做 **前調查**，以免白忙一場。

> 補充：如果 技術貢獻(4) 沒有做的很好，那麼接受更多的 創意上的貢獻(5) 作為補強。

## Consequences

在確定了專題題目的所需元素後，我認為：

1. 被助教拒絕得可能性更低

因為我們釐清了要求。

2. 有一個更加具體的目標

如此，大家才知道自己應該做什麼，為 [T-001](/tasks/T-001/T-001.md) 打下基礎。
